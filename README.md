# Витрина болидов (курсовой фронт)

Сделал магазин болидов Формулы-1 на моках: список с фильтром по категориям, страница товара, корзина, чекаут и экран «заказ принят». Бэкенда нет, всё лежит в `mockProducts.ts`, цены для вида в миллионах рублей.

Корзина пишется в `localStorage`, после оформления кидает на `/confirmation` (туда напрямую зайти не получится без отправки формы — так задумано).

## Как запустить

```
npm install
npm run dev
```

Сборка для проверки:

```
npm run build
```

## Что внутри

React + TS, Vite, роутинг через react-router-dom. Корзина через контекст (`CartProvider` + хук `useCart`). Картинки лежат в `public/bolides` — svg, чтобы не зависеть от внешних ссылок.

Стили в одном `index.css`: тёмная тема, красный акцент, шрифты Outfit и JetBrains Mono для цифр.

## Маршруты

`/`, `/product/:id`, `/cart`, `/checkout`, `/confirmation` — по названию и так понятно.
